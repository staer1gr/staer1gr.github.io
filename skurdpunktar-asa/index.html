Þyngdarstig æfingahlutans

Í æfingahlutanum færðu vísbendingar skref fyrir skref og sama dæmið bíður þar til það er rétt. Fimihlutinn hefur eitt stig: allar tegundir blandaðar, eins og á prófi, og þar þurfa báðir skurðpunktarnir að vera réttir.

    Skurðpunktar við ásana
    • Við y-ásinn er x = 0. Settu x = 0 inn í jöfnuna — svarið er alltaf k: y = x − 2  →  y = 0 − 2 = −2    punkturinn (0, −2)
    • Við x-ásinn er y = 0. Settu y = 0 inn og leystu jöfnuna: 0 = −2x + 2  →  2x = 2  →  x = 1    punkturinn (1, 0)
    • Lína gegnum (0, 0) sker báða ásana í upphafspunktinum.
    • Lárétt lína y = c (þar sem c ≠ 0) sker y-ásinn í (0, c) en sker aldrei x-ásinn.
