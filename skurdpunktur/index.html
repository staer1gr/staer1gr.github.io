Þyngdarstig æfingahlutans

Í æfingahlutanum færðu vísbendingar skref fyrir skref og sama dæmið bíður þar til það er rétt. Fimihlutinn hefur eitt stig: allar tegundir blandaðar, eins og á prófi, og þar þurfa bæði hnitin að vera rétt.

    Að reikna skurðpunkt tveggja lína
    • Í skurðpunktinum eru báðar línurnar með sama x og sama y. Svarið er punktur (x, y).
    • Komdu báðum jöfnunum á formið y = hx + k og settu hægri hliðarnar jafnar: x + 2 = 3x − 4  →  −2x = −6  →  x = 3
    • Settu x inn í aðra hvora jöfnuna til að finna y: y = 3 + 2 = 5    skurðpunkturinn er (3, 5)
    • Ef x stendur eitt og sér í annarri jöfnunni (t.d. x = 2y) er oft þægilegra að setja það beint inn í hina jöfnuna (innsetningaraðferð, substitution).
    • Lárétt lína y = c gefur y beint og lóðrétt lína x = c gefur x beint.
    • Ef línurnar hafa sömu hallatölu en ólíkt k eru þær samsíða og skerast ekki.
