Blandaðar æfingar: skurðpunktar

Fimihluti sem blandar báðum tegundum á víxl: skurðpunktur tveggja lína, svo skurðpunktar línu við ása hnitakerfisins. Ný dæmi í hvert skipti — engin tvö eins.

Fimihluti: dæmin skiptast á — tvær línur, ásarnir, tvær línur …

Rétt í röð
Heiltala eða brot, t.d. −3 eða 3/2
Skurðpunktur tveggja lína: settu hægri hliðarnar jafnar, finndu x og settu það inn til að finna y. Samsíða línur skerast ekki.
Skurðpunktar við ásana: við y-ásinn er x = 0, svo punkturinn er (0, k). Við x-ásinn er y = 0 — leystu 0 = hx + k.
